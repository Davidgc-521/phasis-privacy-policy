# Política de privacidad de Phasis — borrador

**No publiques todavía este borrador sin completar la identificación del responsable legal, su domicilio y las condiciones aplicables a menores, y sin verificar la versión final de la app y sus SDK de terceros.**

Este paquete se creó a partir del archivo `PRIVACY_POLICY.md` que ya existía dentro del proyecto Phasis 1.10.0. No es una evaluación ni aprobación legal.

## Archivos

- `index.html`: página estática adaptable para GitHub Pages, con decoración y texto de la política.
- `politica-privacidad.txt`: versión de texto plano solicitada.
- `PRIVACY_POLICY.md`: borrador editable en Markdown.

## Publicación cuando esté revisada

1. Crea un repositorio **público** llamado `phasis-privacy-policy` en GitHub.
2. Sube los 4 archivos a la raíz del repositorio (no hace falta publicar el código de la app).
3. Ve a **Settings → Pages → Build and deployment → Source: Deploy from a branch → main / (root) → Save**.
4. Espera la publicación y comprueba la URL desde una ventana privada, sin iniciar sesión.
5. Usa `https://TU-USUARIO.github.io/phasis-privacy-policy/` en Play Console y dentro de la app; el enlace directo al texto es `https://TU-USUARIO.github.io/phasis-privacy-policy/politica-privacidad.txt`.

Si la política incluye datos desactualizados de recopilación, uso, terceros o retención, corrígelos antes de compartirla. La información debe coincidir con la app distribuida y las declaraciones de Play Console.
