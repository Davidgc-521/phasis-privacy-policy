Phasis es una herramienta de registro menstrual, bienestar y salud urinaria. **No es un dispositivo médico ni diagnostica, trata, cura o previene enfermedades; consulta a un profesional sanitario.** Las predicciones no sirven como anticonceptivo.

**Audiencia actual propuesta:** 16 años o más; 16–17 sin publicidad; menores de 16 no admitidos en esta versión. La fecha de nacimiento se evalúa localmente y no se conserva, solamente la categoría de edad declarada.

Esta política corresponde a los cambios del código 1.10.1 del paquete que acompaña estos documentos. Hasta que esa versión sea distribuida y esta web se actualice, es posible que otras versiones instaladas se comporten de modo distinto.

**Publicación:** Sustituye los cuatro archivos en la raíz del repositorio `phasis-privacy-policy` y verifica GitHub Pages (`main / (root)`).
